## 1. Summary of Deliverables

- [x] **Durable `JobStore` (`services/controller/store.py`)**:
  - Thread-safe SQLite / PostgreSQL compatible durable state store.
  - Implements atomic job leasing (`claim_next_job`, `renew_lease`) with automatic expiration recovery for crashed or stalled workers.
  - Manages relational state across `execution_jobs`, `candidates`, `executions`, `rewards`, and `audit_events`.
  - Global metrics computation: total jobs, completed count, scorable runs, mean reward, infra errors.
- [x] **Execution Loop Orchestrator (`services/controller/loop.py`)**:
  - `ExecutionLoopOrchestrator` cleanly ties together:
    1. Task retrieval.
    2. Model code generation via `ModelBackend`.
    3. Candidate hashing (`candidate_sha256`) and database persistence.
    4. Isolated dispatch to `SandboxBackend`.
    5. Deterministic scoring via `RewardEngine`.
    6. Tamper-evident audit logging (`AuditEvent`).
    7. Terminal job status transition (`COMPLETED` or `FAILED`).
  - **Cardinal Invariant Enforced**: Infrastructure failures in the sandbox produce `is_scorable=False`, `reward=None`, audit decision `investigate`, and are NEVER scored `0.0`.
- [x] **FastAPI Control Plane REST API (`services/controller/app.py`)**:
  - Bound to `mac-mini` default port `8092` with `127.0.0.1` bind default.
  - Endpoints:
    - `GET /v1/health`: Overall health and backend connectivity status.
    - `GET /v1/metrics`: Global pass rate and reward statistics.
    - `GET /v1/jobs`: Query and filter jobs by state (`PENDING`, `RUNNING`, `COMPLETED`, `FAILED`).
    - `GET /v1/jobs/{job_id}`: Comprehensive inspection of job, candidate code, execution details, and reward score.
    - `POST /v1/jobs/submit`: Submit a programming task into the execution pipeline.
    - `GET /v1/audit/events`: Retrieve immutable audit events.
    - `GET /v1/events/stream`: SSE (Server-Sent Events) live telemetry stream for the web console (WO-10 readiness).
- [x] **Automated Unit Tests (`tests/unit/test_controller.py`)**:
  - 4 test cases verifying:
    1. Atomic lease lifecycle, renewal, and expiration handover.
    2. Full successful pipeline orchestration (model -> sandbox -> reward -> audit).
    3. Unscorable infrastructure error handling.
    4. Full REST API suite (health, submit, get, list, metrics, audit).
