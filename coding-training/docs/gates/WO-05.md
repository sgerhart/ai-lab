## 1. Summary of Deliverables

- [x] **Model Backend Abstractions (`services/model/backend.py`)**:
  - `ModelBackend` protocol: defines typed lifecycle (`load`, `generate`, `capabilities`, `health`).
  - `MockModelBackend`: deterministic mock model with solution synthesis, keyword matching, and programmable responses.
  - `MLXModelBackend`: native Apple Silicon MLX and `mlx-lm` integration with random PRNG seeding, token metrics, unified memory footprint tracking, and safe dry-run fallback.
  - `HttpModelBackend`: lightweight, zero-dependency HTTP client communicating with `ModelWorker` on `mac-studio:8090`.
  - `extract_python_code`: robust AST-verified code extractor stripping fences, markdown preambles, and identifying syntax errors.
- [x] **Mac Studio Model Worker Service (`services/model/app.py`)**:
  - FastAPI daemon for model loading and token generation on `mac-studio` (port `8090`).
  - Endpoints:
    - `GET /v1/health`: backend availability and model load state.
    - `GET /v1/capabilities`: inference, SFT, LoRA, and unified memory architecture reporting.
    - `POST /v1/models/load`: loads pinned model checkpoint by ID and commit revision.
    - `POST /v1/generate`: prompts model with temperature, top_p, and returns structured `GenerationResult`.
- [x] **Evaluation Contracts & Baseline Runner (`packages/contracts/evaluation.py`, `packages/evaluation/baseline.py`)**:
  - Typed contracts: `TaskEvaluationResult`, `SplitMetrics`, `BaselineReport`.
  - `BaselineEvaluator`: evaluates tasks across validation (15 tasks) and test (15 tasks) splits.
  - **Cardinal Invariant Enforced**: Zero disclosure of test bundle inputs or assertions in prompt construction.
  - Syntax error short-circuit: syntax errors are trapped immediately at compile time without sending execution to the sandbox.
- [x] **Evaluation CLI & Artifacts (`scripts/evaluate_baseline.py`)**:
  - CLI runner supporting `--splits val,test`, `--use-reference`, `--backend mlx|mock`, `--output`.
  - Reference ground-truth ceiling verified: **100.0% pass@1** on holdout splits.
  - Reports generated and persisted:
    - `reports/baseline_holdout.json` (Ground-truth ceiling: 100.0% pass@1, mean reward 1.0000).
    - `reports/baseline_holdout_untrained_mock.json` (Untrained mock: 0.0% pass@1, 100% syntax valid, mean reward 0.0000).
- [x] **Comprehensive Unit Tests (`tests/unit/test_model_backend.py`, `tests/unit/test_baseline_evaluator.py`)**:
  - 10 new test cases covering:
    - Python code extraction across diverse markdown formats.
    - Mock model solution lookup and health checks.
    - MLX backend lifecycle and dry-run fallback.
    - HTTP model client and FastAPI endpoint integration.
    - Zero test vector disclosure in prompts.
    - Syntax error short-circuiting.
    - 100% reference solution verification on both validation and test holdout splits.
    - Baseline report JSON serialization and round-trip verification.
