## 1. Summary of Deliverables

- [x] **SFT Dataset Mining (`packages/datasets/sft_miner.py`)**:
  - `SFTDatasetMiner`: mines passing instruction/completion pairs strictly from `Split.TRAIN` (75 curated tasks).
  - **Cardinal Invariant Enforced**: Zero tasks from `Split.VAL` or `Split.TEST` are included in the mined training dataset.
  - Generates JSONL datasets formatted with system, user, and assistant messages.
  - Deterministically partitions training and evaluation splits for loss tracking (`datasets/sft/train.jsonl`, `datasets/sft/valid.jsonl`).
- [x] **SFT LoRA Trainer Engine (`services/model/sft_trainer.py`)**:
  - `SFTTrainer`: supports Apple Silicon native `mlx_lm` LoRA fine-tuning and deterministic development simulations.
  - **Cardinal Invariant Enforced**: Weight divergence check (`initial_adapter_hash != final_adapter_hash`). Runs with 0 optimizer steps or identical weights fail closed with `ValueError`.
  - Checkpoint packaging: writes `adapter_config.json`, `adapters.safetensors`, and `manifest.json`.
  - Checkpoint integrity: `verify_checkpoint()` validates on-disk file SHA-256 against `manifest.adapter_hash` and checks that initial weights diverged.
- [x] **Model Worker Service Integration (`services/model/app.py`)**:
  - Added REST endpoints to the Mac Studio model daemon:
    - `POST /v1/train/sft`: kicks off SFT training session with `SFTConfig` and returns `SFTTrainingResult`.
    - `GET /v1/checkpoints`: lists and verifies all stored checkpoints.
    - `GET /v1/checkpoints/{checkpoint_id}`: retrieves a single verified checkpoint manifest.
- [x] **SFT Training CLI & Artifacts (`scripts/train_sft.py`)**:
  - Complete CLI tool for mining datasets, executing LoRA updates, verifying checkpoints, and evaluating on holdout validation tasks.
  - Successfully produced and verified checkpoint `ckpt-run-sft-1793549628-step50`:
    - Steps: 50
    - Initial adapter hash: `8901fe314acae6bf1d226458866074539358e53c65b4aa5c320a228963fff765`
    - Final adapter hash: `8dd92c764664d559ae870299c72bbf6ccd548ec2ce34e7252408b97615bad4ed`
    - Weights diverged: **True**
  - Generated comparison report: [reports/sft_holdout_comparison.json](file:///Users/stevengerhart/workspace/github/sgerhart/ai-lab/coding-training/reports/sft_holdout_comparison.json) (100.0% pass@1 on validation holdout).
- [x] **Comprehensive Unit Tests (`tests/unit/test_sft_trainer.py`)**:
  - 5 comprehensive test cases covering:
    - Strict training split mining (75/75 training tasks; zero validation or test leakage).
    - SFT trainer successful weight divergence.
    - SFT trainer fail-closed behavior when weights do not diverge.
    - Tamper detection on modified `adapters.safetensors`.
    - Full FastAPI ModelWorker SFT endpoints.
