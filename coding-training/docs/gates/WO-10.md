## 1. Summary of Deliverables

- [x] **React 18 + Vite + TypeScript Console Frontend (`coding-training/console/`)**:
  - Modular frontend built with standard component hierarchy and TypeScript type safety (`verbatimModuleSyntax` compliant).
  - Glassmorphic dark design system (`src/index.css`) matching the AI Lab aesthetic (`#090d16`, `#111827`, `#1e293b`) with tailored semantic accents (cyan `#38bdf8`, emerald `#10b981`, amber `#f59e0b`, rose `#f43f5e`, purple `#a855f7`).
  - Production build bundle generated at `coding-training/console/dist/` in 488ms with zero compile errors.
- [x] **6 Dedicated Operator Views**:
  - **Dashboard (`DashboardView.tsx`)**: High-level KPI summary cards (Total Tasks: 105, Verified Checkpoints, Active Runs, Pass@1), cluster host topology status (`mac-mini: 8000`, `mac-studio: 8001`, `proxmox: 8002`), quick action launchers, and recent training runs.
  - **Playground (`PlaygroundView.tsx`)**: Interactive task selector, model selector, candidate code editor, "Run in Sandbox" dispatcher, live test assertion progress bar, stdout/stderr terminal log, and deterministic reward scoring.
  - **Experiments (`ExperimentsView.tsx`)**: SFT LoRA and RL GRPO experiment configuration wizard, mandatory human approval confirmation modal (enforcing `TRAINING_ENABLED` gate), SVG dynamic loss/reward curves, and filterable runs table.
  - **Monitor (`MonitorView.tsx`)**: Real-time SSE telemetry connection (`/v1/events/stream`), worker heartbeat status, live filtered execution log viewer with regex search and log-level filtering.
  - **Models (`ModelsView.tsx`)**: Catalog of base models (`Qwen/Qwen3-0.6B`, `DeepSeek-Coder-1.3B`), verified on-disk LoRA checkpoints with cryptographic SHA-256 digests, parameter divergence badges, and deploy-to-service controls.
  - **Datasets (`DatasetsView.tsx`)**: Catalog browser for all 105 verified Python programming tasks, split filtering (`train`, `val`, `test`), difficulty filtering, and task inspection modal with quarantined hidden test bundle boundaries.
- [x] **Controller API & Static Mount (`services/controller/app.py`)**:
  - Implemented `/v1/tasks` catalog endpoint supporting split and difficulty query parameters.
  - Implemented `/v1/models` catalog endpoint scanning `~/.ai-lab/models/adapters/` for verified checkpoints.
  - Mounted compiled static bundle at `/console` via Starlette `StaticFiles(html=True)`.
  - Added root redirect (`GET /` -> `307 Redirect` -> `/console/`).
  - Integrated Server-Sent Events (SSE) telemetry streaming at `/v1/events/stream`.
- [x] **Automated Testing & Invariant Verification**:
  - Unit tests added in `tests/unit/test_controller.py`: `test_controller_tasks_api`, `test_controller_models_api`, `test_controller_console_mount_and_redirect`, `test_controller_sse_stream`.
  - All 71 tests in `coding-training/` pass in `make check`.
  - Zero browser execution: all sandbox evaluation strictly routes to the isolated Proxmox Linux worker.
