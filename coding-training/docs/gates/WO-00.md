## 3. Verified Constraints & Invariants

1. **Host Execution Prohibition:** Zero candidate code runs on `mac-mini`, `mac-studio`, or `mac-air`. All candidate code runs inside disposable rootless jails on the Proxmox Linux VM.
2. **Safe Defaults Active:**
   - `EXECUTION_ENABLED=false`
   - `TRAINING_ENABLED=false`
   - `RL_ENABLED=false`
   - `SANDBOX_NETWORK_POLICY=deny_all`
3. **Infrastructure Failure Distinction:** Test runner crashes, worker timeouts, and bundle mismatches are scored as `unscorable` / `infra_error` and NEVER assigned a reward score of zero.
