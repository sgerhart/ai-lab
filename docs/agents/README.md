# Agents (documentation)

Code and policies: [`../../agents/`](../../agents/README.md).

- Coding Assistant: read the workspace; patch and commit only in an isolated worktree after exact approval. No push.
- Development: bounded git workflow, approvals for push/merge (policy ahead of the live coding path)
- Research: sourced reports, no fabricated citations
- Lab operations: **read-only**
