# Glossary

| Term | Meaning |
|------|---------|
| **ai-lab** | This repository and the three-host environment it describes |
| **Air** | M3 MacBook Air, human plane |
| **Apply** | `setup.sh --apply` or compose `up` — mutates a host |
| **Control plane** | M1 mini services and harness |
| **Compute plane** | Studio inference and workers |
| **Harness** | Work-order lifecycle, routing, tools, approvals |
| **MagicDNS** | Tailscale names; placeholders in Git |
| **Overlay** | Gitignored file with real IPs/names |
| **Preflight** | Checks only; no changes |
| **Privileged action** | Push, merge, deploy, restore, firewall, brew apply |
| **Qdrant** | Vector DB on the M1 |
| **Scaffolded** | Files exist; behavior not claimed complete |
| **Studio** | M5 Max Mac Studio |
| **Tailnet** | Private Tailscale network |
| **Work order** | Durable unit of agent work |
