    How to authenticate the lab site and open Studio without SSH tunnels.
    
        
    Sign in (username + password)
    
        
    
          
    Use the Sign in dialog (username + password). On the mini, create your operator account once:
    
          
    cd ~/workspace/github/sgerhart/ai-lab
./scripts/set-operator-password.sh
    
          
    The password hash stays in ~/.ai-lab/operator.json (never Git). A session token is stored in your browser only.
    
        
    
        
    Lab API bearer token
    
        
    
          
    Optional for scripts and non-browser clients. Prefer username/password in the browser.
    
          
    With AI_LAB_AUTH_MODE=trusted_tailnet, Tailscale/loopback browsers can call the API without a pasted token.
    
          
    Script fallback: the token lives on mac-mini (do not paste into chat):
    
          
    ssh mac-mini 'test -f ~/.ai-lab/api.token && echo present'
