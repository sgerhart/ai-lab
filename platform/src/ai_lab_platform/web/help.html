Operator guide

How to authenticate the lab site and open Studio without SSH tunnels.

Lab API bearer token (AI_LAB_API_TOKEN)

Preferred: with AI_LAB_AUTH_MODE=trusted_tailnet on the mini, browsers on your Tailscale network (or loopback) do not need to paste a token. The top nav shows “Signed in via Tailscale”.

Optional fallback (non-tailnet clients): the token lives on mac-mini:

ssh mac-mini 'cat ~/.ai-lab/api.token'

This is not an OpenAI/Anthropic key. Keep the API off the public Internet.

From Lab, paste the lab token, then Open Jupyter. No ssh -L required when Studio listens on Tailscale.
